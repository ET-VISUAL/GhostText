Данный проект посвящен преобразованию текста посредсвом шифра Цезаря и шифра Атбаша.

## Возможности
На сайте есть возможность преобразовать текст через шифр Цезаря используя сдвиги (1-25). Также можно наоборот вложить зашифрованный текст и попробовать расшифровать его.

Если хотите просто "отзеркалить буквы алфавита", то вам в этом поможет шифр Атбаша (пока доступен только в нижнем регистре!)

## Инструкция
Есть два варианта запуска
## Вариант 1
Клонируйте репозиторий 
<pre>https://github.com/ET-VISUAL/GhostText.git</pre>

далее переходите в мой проект
<pre>cd GhostText</pre>

Заходите в vs code и нажмите F5 (или скачайте расширение live server)

## Вариант 2
Зайдите в любой браузер
Перейдите по ссылке
```https://et-ghosttext.netlify.app/```
Пожалуйста подождите какое то время и потом можете использовать Шифратор!
